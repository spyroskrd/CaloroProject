# CaloroProject
A simple Umbraco project. Website with Meal Prep Ideas.

## Features
- Home Page
- Dynamic components
- Block List rendering
- Textstring fields
- Color Picker
- Media Picker
- Repeatable Textstrings
- Three.js 3D dumbbell and egg animation

## Technologies
- Umbraco 13.4
- ASP.NET Core
- Razor
- Three.js
- GitHub
